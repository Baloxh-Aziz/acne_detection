# 🧴 Acne Detection with YOLO

A simple web app that finds acne on face images using a YOLO model.

You upload a photo. The app looks at it and shows where the acne is.

👉 [Live Demo](https://acnedetection-skin-disease.streamlit.app/)

---

## ⚠️ Important Note

This project is for **learning and study only**.
It is **not a medical tool**. For skin problems, please ask a skin doctor.

---

## What It Does

- Lets you upload a face image
- Shows the image you uploaded
- Runs the YOLO model on it
- Shows the result with boxes around the detected acne

---

## Files in This Project

| File | What it is |
